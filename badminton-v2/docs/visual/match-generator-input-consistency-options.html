Match Generator — three ways to make "tune a number" one pattern

Match Rules and Optimizer settings are sliders with no way to type an exact value; Scoring Weights are number inputs with no slider to explore the range. Same underlying task — adjust a bounded number — two different controls, so the admin re-learns the interaction mid-panel. All three mocks apply one pattern to both a Match Rules-style field (Number of Matches, range 1-50) and a Scoring Weights-style field (Fairness Penalty, unbounded, default 5000). Try dragging and typing in each.

Option A

Slider + number box, every field

Every field gets both: drag the slider for a quick feel, or type the exact number in the box beside it — they stay in sync. Most capable option and closest to "just add what's missing" rather than removing anything, but every row grows to two controls, which is more real estate across 17 fields than either control alone.

Option B

Number input everywhere, no sliders

Drops sliders entirely — every field becomes a plain number input, matching Scoring Weights today. Simplest markup, most precise for an admin who already knows the value they want (which, per the review, is most weeks). Loses the drag-to-explore feel for someone unsure what range is reasonable, e.g. a first-time admin tuning Number of Matches.

Option C

One control: the slider's value is itself editable

Keeps a single row per field — the number shown beside the slider looks like a value display but is actually a text input (dashed underline signals it's editable). Drag for a feel, or tap the number to type exactly, without doubling every row into two controls. Most elegant on space, but the "this number is secretly editable" affordance is less obvious than a bordered input box.
