Player dropdown — five ways to make the “⇄ swap” row look different

Today a player already in the match reads Marcus Lim ⇄ swap in the same white text as everyone else, so the row only separates itself once you read to the end of the name. Below are five treatments for the same list. Each card has a live dropdown you can open, and a mock of the open list beside it so all five can be compared without clicking through them one at a time.

One constraint decides a lot of this. These are native <select> elements. Desktop Chrome honours color and font-weight on an <option>, but the iOS and Android system pickers throw all of it away and render plain text. So a colour-only fix is invisible on a phone — and the phone is where this edit form actually gets used courtside. Anything carried in the text (an arrow, a group header) survives everywhere.
Option A

Colour and weight only

Same text as today, but the swap rows are teal and bold. One CSS rule, no wording change, nothing moves. The weakest of the five on a phone, where it degrades to exactly what you have now.

Option B

Arrow in front, name after

Move the marker to the start: ⇄ Gellie — swap. Every swap row now begins with the same glyph, so they line up as a column down the left edge and you spot them without reading. Pure text, so it survives the iOS and Android pickers untouched.

Option C

Split into two groups

Stop marking rows and separate them instead. An <optgroup> puts the in-match players under their own bold italic header, indented, above everyone else — so the swap candidates are found by position, not by reading. Native headers render on mobile too.

Option E

Custom dropdown with a badge

Drop the native picker and render the list yourself: a teal Swap pill on the right, app colours, the same look on every device. Total control — and the only option that looks identical on desktop and phone. It is also the only one that is real work: keyboard handling, focus, scroll and screen-reader roles all become ours.
