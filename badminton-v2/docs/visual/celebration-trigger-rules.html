When a leaderboard celebration fires

Four gates that can stop the whole thing, then one ladder of four achievements evaluated per board, highest first. The first rung that matches wins and the rest are not considered. Source of truth: src/lib/podiumCelebration.ts.

Gates — only one of these filters anything

On a normal launch Gate 2 is the only one that stops anything. Auth is remembered, so Gate 1 is true for every returning player — it is a guard against evaluating with no player id on the login screen, not a filter. Gate 3 fires once ever per player. Gate 4 is a per-board detail.

GATE 2

Has any session completed?

One small query for the latest completed_at. Unchanged since last time means no rank can have moved.

✕ unchanged → stop, no board queries at all

GATE 3

Seen this player before?

No stored snapshot means the very first evaluation. It records standings and says nothing.

✕ first ever run → record silently
›
GATE 4

Per board: placed, and watched before?

An unplaced board has no news. A board absent from the last snapshot was not being watched then, so its standing is not new.

✕ either → skip that board

The ladder — first match wins, per board

A fourth rung, personal best, was removed. There is no rank history in the database, so the app could only ever know the best this browser had seen since the feature first ran — “Your best yet!” was false for anyone who peaked earlier. Those moments now read as a climb.

rank ≤ 3 && (previousRank === null || previousRank > rank)

Reached the top 3, or improved inside it. The only kind that earns a 3px medal-coloured edge; every other kind gets the ordinary border and the bunny.

5th → 3rd fires. 3rd → 1st fires. 2nd → 2nd does not.

2
🐰 First appearance plain border
previousRank === null && bestEver[board] === undefined

On this board for the very first time. bestEver is what separates it from a return — someone who held a place, fell off and came back has not just arrived.

unplaced → 8th, never placed before, fires. Unplaced → 9th with a best of 7th does not.

3
🐰 Climb plain border
previousRank !== null && previousRank − rank ≥ 1

Any improvement at all — now the rung that catches every ordinary gain outside the top 3.

7th → 6th fires, reading “Up 1 place!”. 9th → 6th reads “Up 3 places!”.

—
No celebration

Unchanged, worse, or dropped off the board. The feature never reports bad news.

When several boards match at once

Every watched board is evaluated, so one session can produce several achievements. They are sorted by kind first (podium → first appearance → climb), then by rank (5th beats 6th), then by board (Individual, Partners, then cheer categories). One card lists them all; the toast names the top one and counts the rest. Never a queue of cards.

Boards watched: Individual, Partners, and each of the six Cheers categories — eight in all. Awards is excluded: single holder, no 2nd or 3rd, so there is no placing to detect.
