Match Generator — three ways to make weight help reachable by touch

Right now every explanation (help strings on each weight, plus the Info icon next to Max Skill Gap) is a bare title= attribute — hover-only, on a tool the app's own review already established is meant to run courtside on a phone. All three mocks use the real copy for Repeat Partner Penalty and Rest Spacing Penalty. Tap the icons / links to try each.

Option A

Tap-to-reveal popover per field

Same Info-icon affordance already used for Max Skill Gap, extended to every weight, but tapping (not hovering) opens a small floating card with that field's explanation. Closest to today's pattern — the icon is still exactly where the eye already looks — but it's 12 new tappable targets in an already-dense panel, and only one explanation is visible at a time.

Option B

Permanent inline help under every field

No tap needed — the one-line explanation is always visible in muted text under each field's inputs. Zero new interactions, and every explanation is scannable at once without hunting for icons. Costs real vertical space across 12 fields (roughly two extra lines each), which matters on a panel the critique already flagged as dense.

Option C

One glossary link for everything

A single “What do these mean?” link at the top of Scoring Weights opens a full-screen reference sheet listing all 12 definitions at once — read once, then close it and tune. No per-field icons, no lost space in the normal view, but the explanation is separated from the exact field it describes, so the admin has to remember which weight they were looking at.
