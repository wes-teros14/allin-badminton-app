Seed matches — three places the pin controls could live

Same feature, same engine hooks, three different homes on the admin’s Match Schedule panel (MatchGeneratorPanel, phone width). All three are clickable: tick, pin, set and regenerate to feel the flow. The picker itself is the existing four-dropdown edit form in every case — only where it appears and when you reach it changes.

Option A

Inside Settings, before you generate

A Fixed Opening Games section next to the other generator rules. Tick Pin on a game, fill four slots, then Generate. Hidden until Settings is expanded, so the default panel is unchanged.

Option B

Pin from the preview, after you generate

Generate first. Games 1–2 in the preview get a Pin toggle beside Edit. Pin a generated game you like as-is, or edit it and then pin it. Generate Again keeps pinned rows.
