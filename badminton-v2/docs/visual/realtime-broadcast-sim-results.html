*The old run's first change was counted as part of the second, because both courts started at the same moment. It is a counting quirk, not a missed update.

What this proves: the new way removes the poll entirely, so the database does about half the work for the same session, and every phone still gets every update.

What it doesn't prove: the DEV server is not short of memory the way prod is, so this cannot show prod's stalls disappearing. The first real session after the rollout will tell.

Still unexplained: one phone dropped its connection briefly. Watch for the “Reconnecting…” badge on the live board.
